配置微信读书登录

文章列表已从公众号后台迁移到微信读书 Web。凭证只保存在本机 data/.weread_credentials.json。

Cookie 属于登录凭证，请勿截图、上传或发到聊天中。扫码完成后，凭证只会保存在本机。

已有有效凭证后：扫码刷新 Cookie

扫码不能完成首次登录，只能刷新普通 Web Cookie，并尝试续期本机已有的同账号文章列表票据。如果尚未通过完整 cURL 看到过一次“微信读书凭证有效，发现 N 个公众号”，请勿重复扫码，先完成下方的首次登录。

请使用微信扫码

首次登录（必须成功一次）：导入完整 cURL

  1. 在微信读书 App 中关注目标公众号，使其出现在书架。
  2. 浏览器登录与扫码相同的 weread.qq.com 账号，打开书架中的任一公众号文章列表。
  3. 在开发者工具 Network 中找到响应成功的 /web/mp/articles再右键选择“Copy as cURL”。不要选择其他请求。
  4. 只在下面的本机表单中粘贴完整 cURL，并点击“校验并保存”。看到“微信读书凭证有效，发现 N 个公众号”才表示首次登录完成。
